NEKO BOT — PHONE BUILD PROJECT

Cara paling ringan:
1. Buat repository GitHub dari HP.
2. Upload semua isi folder proyek ini.
3. Buka tab Actions.
4. Pilih "Build NEKO BOT APK".
5. Jalankan "Run workflow".
6. Setelah selesai, download artifact "NEKO-BOT-debug-apk".
7. Extract artifact ZIP dan install app-debug.apk di HP.

Folder www/ berisi kontrol web NEKO yang diekstrak dari firmware.
